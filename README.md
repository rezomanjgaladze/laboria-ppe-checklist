# Laboria Safety Checklists

Digital health and safety inspection checklists for modern workplaces.

A professional inspection workspace for safety managers, auditors, and supervisors.

## Development

Run the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production

Public production URL:

[https://laboria-ppe-checklist.vercel.app](https://laboria-ppe-checklist.vercel.app)
